# FoodCall Tailwind Design Token Reference

Reference documentation for the production scaffold. Values come from `prototype/FoodCall/index.html` and `FoodCall Prototype.md`; the premium prototype is not the source of truth.

| CSS variable | Value | Tailwind token | Usage |
| --- | --- | --- | --- |
| `--primary` | `#EA580B` | `colors.primary` | Primary buttons, active navigation, scores |
| `--secondary` | `#F59E0B` | `colors.secondary` | Warm gradient endpoint |
| `--success` | `#16A34A` | `colors.success` | Positive states and success pills |
| `--danger` | `#DC2626` | `colors.danger` | Destructive states |
| `--bg` | `#FFEDD5` | `colors.bg` | App background |
| `--surface` | `#FFFFFF` | `colors.surface` | Main card surfaces |
| `--surface-warm` | `#FFF8F0` | `colors.surface-warm` | Warm nested card surfaces |
| `--fg` | `#1D1820` | `colors.fg` | Primary text |
| `--muted` | `#6D6572` | `colors.muted` | Secondary text |
| `--border` | `#F0D4B8` | `colors.border` | Borders and separators |
| `--soft` | `#F4E4D2` | `colors.soft` | Soft backgrounds |
| `--radius` | `24px` | `borderRadius.card`, `borderRadius.radius` | Rounded cards and shells |
| display font | `Limelight` | `fontFamily.display` | Hero titles and brand accents |
| body font | `system-ui` | `fontFamily.body` | Main UI copy |
| mono font | `JetBrains Mono` | `fontFamily.mono` | Scores and numeric data |
| breakpoint md | `680px` | `screens.md` | Mobile-to-tablet layout switch |
| breakpoint lg | `1180px` | `screens.lg` | Desktop grid layout switch |
